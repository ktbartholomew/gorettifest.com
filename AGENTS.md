# Writing and design

Apply these rules to all writing and design work in this repository, including
website copy, UI labels, documentation, code comments, and assistant responses.

- Skip fluff asides, decorative commentary, emotional filler, and generic slogans.
- Do not add headings, subheadings, eyebrow labels, captions, or closing lines
  merely to fill space or create a mood.
- Use direct, specific language that conveys information or helps someone act.
  Omit text that adds neither.
- Write social captions in a direct, positive, sincere voice: casual but
  professional. Use puns or familiar phrases when they fit the photo, without
  forcing them. Never use overly emotional or maudlin language.
- Keep necessary context, accessibility labels, and comments explaining non-obvious
  behavior. Warmth is welcome when it serves the message; manufactured sentiment
  is not.
- Examples to avoid: "A few moments. A whole lot of heart," "The weekend,
  remembered," "You're part of the story," and "More than a weekend."
