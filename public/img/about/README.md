# GorettiFest infographic icons

These SVGs contain vector paths extracted from the two-page
`2025 Infographic (02-2).pdf` (source document, not bundled with the site). Each icon is isolated from
the page artwork; the PDF's blue fills and strokes are replaced by `currentColor`.
The About page uses them as decorative CSS masks so all visible colors come from
the site's existing Tailwind theme. Statistics and labels are rendered as HTML,
using the site's fonts, rather than embedded in an image.

Page 1 supplies the attendance, ticket, donor, and food icons. Page 2 supplies
the volunteer, entertainment, activity, and community impact icons.
